### 🐾 Available Features

- Rarity based item highlights,
- ...and more to come soon!

### 🐾 Contributing

It is highly recommended to use IntelliJ IDEA in combination with the Minecraft Development plugin to provide the most optimal setup for contributing.

This is nothing more than a personal passion project, so expect open issues/PRs to take some time to be reviewed!
